# Estudos de MongoDB

Repositório dedicado aos meus estudos de bancos de dados NoSQL utilizando MongoDB e mongosh, durante minha formação em Análise e Desenvolvimento de Sistemas.

## Conteúdo estudado

- Operações CRUD: inserção, consulta, atualização e exclusão de documentos.
- Consultas com `find()` e operadores de comparação.
- Aggregation Framework: `$match`, `$project`, `$group`, `$sort` e `$limit`.
- Operadores de atualização: `$set`, `$unset` e `$mul`.
- Contagem de documentos com `countDocuments()`.
- Manipulação de coleções e documentos JSON.

## Organização do projeto

- `AtividadesAvaliativas/` — exercícios e atividades.
- `Collections/` — arquivos JSON das coleções utilizadas nos estudos.
- `Prova/` — materiais de estudo e exercícios.
- `Scripts/` — scripts de consultas e operações MongoDB.

## Tecnologias utilizadas

- MongoDB
- MongoDB Compass
- MongoDB Shell (mongosh)
- JavaScript
- Visual Studio Code

## Objetivo

Documentar minha evolução em bancos de dados não relacionais e aplicar os conhecimentos adquiridos na faculdade.
